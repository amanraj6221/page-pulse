#  Page Pulse

A modern Website Performance & SEO Analyzer built using React and Node.js.

## Features

- Analyze any website
- HTTP Status
- Response Time
- Page Title
- Meta Description
- H1 Count
- Images Missing Alt
- Word Count

## Tech Stack

Frontend
- React
- Vite
- Axios

Backend
- Node.js
- Express
- Axios
- Cheerio

Deployment
- Vercel
- Render
